# 🖥️ Srivatsav Devarakonda — Personal Portfolio

A cyber-themed personal portfolio website built with vanilla HTML, CSS, and JavaScript. Features an interactive terminal, animated particle systems, radar skill charts, and a clean responsive design — deployed on Vercel.

🔗 **Live Demo:** [vatsav-portfolio.vercel.app](https://vatsav-portfolio.vercel.app)

## 📸 Preview

## 🚀 Getting Started

No installation or build step required.

**Option 1 — Open directly:**
```bash
git clone https://github.com/srivatsavdevarakonda/portfolio.git
cd portfolio
open index.html   # or just double-click the file
```

**Option 2 — Serve locally** (recommended to avoid any CORS quirks):
```bash
# Using Python
python3 -m http.server 8000

# Or using Node's http-server
npx http-server .
```

Then visit `http://localhost:8000` in your browser.

## 🌐 Deployment

This site is deployed on **Vercel** via GitHub integration.

To deploy your own fork:
1. Fork this repository
2. Go to [vercel.com](https://vercel.com) → **New Project**
3. Import your forked repo
4. Vercel auto-detects static HTML — hit **Deploy**

No build configuration needed.

---

## 🧩 Customization

To adapt this portfolio for yourself:

1. **Personal info** — Edit name, bio, and social links in `index.html`
2. **Profile photo** — Replace `profile.jpg` with your own (keep the same filename or update the `src` in HTML)
3. **Resume** — Replace `CV.pdf` with your own PDF
4. **Projects & Experience** — Update the relevant sections in `index.html`
5. **Color theme** — CSS custom properties are defined at the top of `styles.css` for easy theming
6. **Animations** — Terminal text and particle behavior can be tweaked in `script.js`
